# Guide Pratique — Disney Dreamlight Valley : La Mer des Souvenirs

Mini-application web prête pour **GitHub Pages** et optimisée pour l'impression en **livret A5 sur fond blanc**.

## Structure des dossiers
- `index.html` : l'application complète (recherche, filtres, fiches compagnons, 37 recettes, section craft et mode impression A5).
- `data.json` : toutes les données structurées en français.
- `images/compagnons/` : glissez ici les images des compagnons (`toucan.png`, `meringuin.png`, `axolotl.png`).
- `images/recettes/` : glissez ici les images des plats (noms indiqués dans le tableau ci-dessous).
- `images/craft/` : glissez ici les images des objets/ressources de craft.
- `assets/icons/` : dossier optionnel pour vos icônes personnalisées.

## Activer GitHub Pages
1. Déposez le contenu de ce dossier à la racine de votre dépôt GitHub.
2. Allez dans **Settings > Pages**.
3. Choisissez la branche **main** et le dossier **/(root)**, puis sauvegardez.
